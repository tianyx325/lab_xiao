FEDD-Net: A Frequency Diagonal Feature Enhanced Dual-Branch Diffusion Network for Low-Light Image Enhancement
Separates high/low frequencies with dual-tree complex wavelets, applies cross-attention across directions in the frequency domain to enhance diagonal features, and generates low-frequency structure and high-frequency detail via two diffusion paths.
PUB2025· ICASSP DOI Code
Diffusion Model with Multi-layer Wavelet Transform for Low-Light Image Enhancement
Replaces convolutional up/downsampling with multi-level wavelet transforms to extract multi-scale features with global refinement in diffusion models for low-light enhancement.
PUB2025· ICASSP DOI Code
NCNet: Learning to Find Non-Consistent Correspondence Using Learnable Frequency Response Function
Fits both consistent and inconsistent true matches with learnable frequency responses, avoiding discarding valid correspondences based solely on motion consistency.
PUB2024· ICIP DOI
A Cnn-Transformer Network Based Snr Guided High Frequency Reconstruction for Low Light Image Enhancement
Splits low-light images into high- and low-frequency bands and uses a low-frequency SNR map to guide convolution and Transformer recovery of high-frequency textures.
PUB2024· ICANN DOI
EDAFormer: Enhancing Low-Light Images with a Dual-Attention Transformer
Fuses global and local attention recursively and adds multi-scale context convolutional self-attention to enhance low-light images.
PUB2024· IJCNN DOI
A Multi-Exposure Generation and Fusion Method for Low-Light Image Enhancement
Generates images at multiple exposures following multi-exposure distributions, then fuses features with perceptual importance and curve adjustment to enhance low-light images.

SPGFusion: A Semantic Prior Guided Infrared and Visible Image Fusion Network
Guides infrared–visible image fusion with a semantic-feature-aware module and a semantic adversarial loss.

CEDFlow: Latent Contour Enhancement for Dark Optical Flow Estimation
Encodes motion in latent space with spatial–frequency decomposition and filters large-scale contours with second-order difference of Gaussians to estimate low-light optical flow.
PUB2024· ICME DOI
A Channel-Wise Guidance Sparse Transformer for Effective Dark Image Enhancement
Selects key representations by channel thresholding, keeps only useful self-attention, and reconstructs low-light images with a bidirectional gated feed-forward network.
